# Repository Instructions — Colour and Effects Catalogue SPA

A dependency-free static SPA for miniature painters to browse paint catalogues, textures, bench-test data and project build logs.

---

## Framework & Architecture Restrictions

### ❌ Forbidden
- No frameworks (React, Vue, Svelte, Astro, Angular)
- No build tools (Webpack, Vite, npm scripts beyond `playwright test`)
- No transpilers (Babel, TypeScript)
- No framework scaffolding or generators

### ✅ Required Stack
- Vanilla JavaScript (ES6+ only)
- HTML5 semantic markup
- CSS3 (dark medieval theme)
- CDN-only external dependencies (Bootstrap 5.3 JS, Icons, Google Fonts)
- Playwright E2E tests in `./tests/`

## Key Control Points (Required Patterns)

### 1. Constants — Never Use Hardcoded Strings
**File:** `js/app.js` lines 8-37  
**Pattern:**
```javascript
// Use these instead of magic strings:
TAB_NAMES.COLOURS, TAB_NAMES.EFFECTS, TAB_NAMES.PROJECTS, TAB_NAMES.PUTTY
FIELD_KEYS.BASE_COLOUR, FIELD_KEYS.CODE, FIELD_KEYS.HEX, etc.
```
**Apply:** sortResults(), projectSort(), displayResults(), any string comparison

### 2. XSS Protection — escapeHtml() Required
**File:** `js/app.js` line 863  
**Pattern:**
```javascript
// SAFE: Always escape before innerHTML
html += `<div>${escapeHtml(item.name)}</div>`;

// UNSAFE: Never do this
html += `<div>${item.name}</div>`;
```
**Apply:** createCard(), createProjectCard(), all dynamic HTML rendering

### 3. URL Validation — isValidUrl() for Links
**File:** `js/app.js` line 843  
**Pattern:**
```javascript
if (isValidUrl(projectUrl)) {
  link.href = projectUrl;  // Safe
} else {
  console.warn('Invalid URL');
}
```
**Blocks:** javascript:, data:, ftp:// protocols

### 4. Filename Validation — Security Gate
**File:** `js/app.js` (PROJECT_IMAGE validation)  
**Pattern:**
```javascript
// Blocks path traversal: ../../, ..\\, etc.
const SAFE_FILENAME_REGEX = /^[a-zA-Z0-9._-]+$/;
if (!SAFE_FILENAME_REGEX.test(filename) || filename.includes('..')) {
  return '';  // Reject unsafe filenames
}
```

### 5. Global State — APP_STATE Object
**File:** `js/app.js` lines 40-73 (consolidation target)  
**Pattern:**
```javascript
const APP_STATE = {
  data: { colours: [], effects: [], projects: [], tools: [] },
  ui: { currentTab: 'colours', sortAsc: true, currentFilteredResults: [] },
  cache: { colorMap: {} }
};
```
**Usage:** `APP_STATE.data.colours`, not `allDataColours`

## Security Requirements

### XSS Prevention
- ✅ All user input must be escaped via escapeHtml() before rendering
- ✅ No innerHTML assignments with unescaped variables
- ✅ Data validation: fields accessed with optional chaining (`field?.toString()`)

### URL Validation
- ✅ Project URLs validated via isValidUrl() before href assignment
- ✅ Blocks protocols: javascript:, data:, ftp://
- ✅ Allows: http://, https:// only

### Filename Validation
- ✅ ProjectImage filenames must match `/^[a-zA-Z0-9._-]+$/`
- ✅ Blocks path traversal: ../, ..\, ../../
- ✅ Blocks absolute paths and UNC paths

### CSP Compliance
- ✅ No inline scripts (move to external .js files)
- ✅ No inline event handlers (onclick, onerror)
- ✅ No eval() or Function() constructors
- ✅ Bootstrap tooltips initialized in js/tooltips.js (external)

## Code Quality Standards

### DRY Principle
- Extract repeated code into functions or constants
- Use FIELD_KEYS and TAB_NAMES instead of magic strings
- Consolidate duplicate function definitions (projectSort, etc.)

### State Management
- Single source of truth: APP_STATE object
- No scattered global variables
- Immutable constants via Object.freeze()

### Naming Conventions
- Functions: camelCase, descriptive (createCard, performSearch, escapeHtml)
- Constants: SCREAMING_SNAKE_CASE (TAB_NAMES, FIELD_KEYS)
- Private helpers: prefix with _ (e.g., _sanitizeInput)

### Testing
- Playwright E2E tests in `./tests/` directory only
- All tests must pass before merge: `npx playwright test`
- Test independence: no global state modifications without cleanup
- Coverage: happy paths, error scenarios, security payloads

## CSS Conventions

### Theme
- **Dark Medieval:** #1a1a2e base, #252632 sections, #2c2c3d accents
- **Gold Accents:** #d4af37 primary, #ffc107 secondary
- **Avoid:** Bright corporate colors (#1a73e8 is forbidden)

### Layout
- Mobile-first: Base styles for mobile, `@media (max-width: 768px)` for overrides
- Flexible: Flexbox/Grid, responsive 360px → 4K
- Consistent: Cards, accordions, tables use shared styling

### Responsive
- Single breakpoint: `@media (max-width: 768px)` for mobile
- Tab buttons: `flex: 1 1 0% !important` (all 4 fit on 360px)
- Card transformation: Block display on mobile, inline labels via ::before

### Fonts
- **Headers (h1, h2, .tab-btn, .card-title):** Cinzel Decorative
- **Body text, descriptions:** Cormorant Garamond
- **Monospace (code, hex codes):** system-ui (built-in)

## When You're Unsure

1. **Where is the feature defined?** → Check FIELD_KEYS or TAB_NAMES in js/app.js
2. **How do I render user data safely?** → Use escapeHtml(data) before innerHTML
3. **Is this URL safe?** → Call isValidUrl(url) before using as href
4. **Can I use a framework?** → **No.** Vanilla JS only.
5. **Should I create a build step?** → **No.** Static files only.
6. **How do I validate filenames?** → Use isValidImageFilename() pattern
7. **What's the app state structure?** → APP_STATE object with .data, .ui, .cache
